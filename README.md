# Diagrama: Flujo de Desarrollo de Software Asistido por IA

Visualizador interactivo y mapa de arquitectura para flujos de ingeniería de software potenciados por agentes de Inteligencia Artificial e investigación científica (Fases 1 a 7).

* **Despliegue en vivo:** [https://alexanderucun.github.io/diagrama-flujo-ia/](https://alexanderucun.github.io/diagrama-flujo-ia/)
* **Repositorio:** [https://github.com/AlexanderUcun/diagrama-flujo-ia](https://github.com/AlexanderUcun/diagrama-flujo-ia)
* **Archivo principal:** `index.html`

## Características Principales
* **Vistas duales:** Alternador rápido entre vista de **Flujo horizontal por fases (⇄)** y **Cuadrícula completa por tarjetas (☷)**.
* **Buscador interactivo y filtros en tiempo real:** Búsqueda instantánea por nombre de herramienta, palabra clave o rol.
* **Modal interactivo:** Clic en cualquier tarjeta o nodo para abrir su ficha técnica detallada (qué hace, cómo ayuda, cuándo usarla y enlaces directos).
* **Jerarquía visual:** Clasificación con insignias de prioridad (Top 1 Oro, Alta Prioridad, Especializado).
* **Paleta visual suave:** Temas Dark y Light calibrados en tonos pizarra (slate), suaves a la vista y sin negros saturados.

## Fases del Flujo de Trabajo
1. **Fase 1: Investigación en Ingeniería de Software, Benchmarks & Papers con Código:** Papers With Code (Top 1 repositorios con papers), arXiv cs.SE / cs.AI (Top 1 preprints Cornell), LMSYS Chatbot Arena (Top 1 coding leaderboard), SWE-bench (Top 1 benchmark de agentes), Hugging Face Papers, Semantic Scholar CS, Connected Papers, SciSpace AI, Overleaf LaTeX, Draw.io UML.
2. **Fase 2: Agentes de Código Autónomos & LLMs:** OpenCode, Everything Claude Code (ECC), Cline, Aider, OpenHands, Claude Code CLI, Files2Prompt, Lovable, Bolt.new, Kimi K3.
3. **Fase 3: Diseño UI/UX & Prevención Anti-AI Slop:** M3E Canvas, Google Modern Web Guidance, Open Design, Apple HIG Skills, Tailwind CSS, GSAP.
4. **Fase 4: Backend, Autenticación Soberana & APIs:** Better Auth, Reverse API Engineer, Cloud Sandboxes.
5. **Fase 5: Testing Autónomo, Calidad & Ciberseguridad:** CodeRabbit AI, Autonoma AI (self-healing tests), Google OSS-Fuzz, REA, EmailOSINT.
6. **Fase 6: Extracción de Datos, Automatización & RAG:** Firecrawl, Agent Reach.
7. **Fase 7: Estrategia SaaS, Analítica de Producto & Crecimiento:** Microsoft Clarity (Top 1 mapas de calor y UX analytics sin límites), MDN Web Docs & Web.dev (Top 1 estándares y Core Web Vitals), Similarweb & Meta Ads Library (inteligencia competitiva y tráfico), Ecosistema MoureDev, SENA/Accenture, Validación y Legal SaaS.
